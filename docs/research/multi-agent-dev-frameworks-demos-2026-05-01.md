## Notes & caveats

- **Verified-good 2025/2026 founder demos:** Symphony (OpenAI blog), Sculptor (Imbue), Conductor (Charlie Holtz/Melty), Vibe Kanban (Sourcegraph stream), claude-flow (WorldofAI deep dive), OpenHands (Neubig webinar), Microsoft Agent Framework (DevUI demo).
- **Brand new, demo-thin (Feb–March 2026 launches):** Composio Agent Orchestrator, OpenAI Symphony, ChatDev 2.0/DevAll. Expect better third-party demos in 30–60 days.
- **Sunsetting / dying:** Roo Code (extension dies May 15 2026 → Roomote cloud agent), Vibe Kanban (per their note, sunsetting but staying open source), Devika (stalled), AutoGen (in maintenance, superseded by Microsoft Agent Framework).
- **No proper YouTube demo, only repo mp4s/gifs:** claude-squad, opcode (mostly), Composio Agent Orchestrator. For these the GitHub README is the source-of-truth artifact.
- **Naming watch:** ruvnet's "claude-flow" repo redirects to "ruflo" (rebrand). Imbue's Sculptor lives at imbue.com/sculptor — not "Sculptor.ai".
